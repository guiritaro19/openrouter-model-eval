# Product direction

A local evaluation workbench for fast classification experiments. No PostgreSQL or Supabase is required. One primary workflow: import cases, map fields, select models, execute, export, then compare against versioned golden answers. Historical raw responses and measured economics remain inspectable.

The user specified a dark, restrained AI Evaluation Lab. Use cool near-black surfaces, a muted mint accent, thin functional dividers and tabular measurements. Manrope is the interface font; IBM Plex Mono is reserved for IDs and technical fields. Keep motion limited to loading indicators and brief control feedback. On narrow screens, stack configuration and candidates; wide tables scroll within their container.

Never display fabricated performance. Fictional input data is explicitly named. Missing usage, costs and accuracy stay empty or NOT MEASURED YET. Costs with incomplete data are not silently summed as zero. Secret credentials live only in the ignored backend env file.
